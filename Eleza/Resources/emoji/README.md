# Emoji pictures

| | |
| --- | --- |
| `emoji.pack` | Telegram Android's emoji (format «EPK3», 3606 emoji of 64×64), the same file the Android client ships (`app/src/main/assets/emoji/emoji.pack`) |
| `compound/0_<tone>_<side>.png` | the halves of 🤝 for the handshakes of two skin tones (tone -1…4, side 0 left / 1 right), from the same place |
| Reader | our own: `lib/ui/ui/emoji/emoji_pack_reader.cpp` |
| Tables | `lib/ui/ui/emoji/emoji_tables_auto.cpp`, generated by `codegen/scripts/gen_emoji_tables.py` from Telegram's `EmojiData.java` of the same revision (data only), with the search words of CLDR |
| Embedded | `qrc/emoji.qrc`, stored uncompressed and read in place |

The pictures are Telegram's (Apple-style) artwork; their licence for redistribution is
the product owner's to settle, as for the Android client. Replacing the pack means
regenerating the tables from the matching `EmojiData.java`: `tests/ui/test_emoji.cpp`
checks that both agree and that every emoji decodes.
